# Architecture Decision Records

Every decision about framer gets its own file here: `NNNN-short-slug.md`, numbered
in order. Files are never deleted. To change a decision, add a new ADR and set the
old one's status to `Superseded by NNNN`.

```markdown
# NNNN. Title

- **Date:** YYYY-MM-DD
- **Status:** Accepted | Superseded by NNNN

## Context

Why a decision was needed.

## Decision

What was decided.

## Consequences

What follows from it, including anything left open.
```
